## Usage

Each clip gets its own screen. Screens arrive `stagger` frames apart: the new one rises out
of a blur into the front, and every screen already there steps back — smaller, and higher,
so its top peeks out above the newest. Screens more than three steps back fade away, so
any number of clips works.

```tsx
import { Composition, staticFile } from "remotion";
import { PhoneStack } from "@/components/snap-cn/phone-stack";

const Scene = () => (
  <PhoneStack
    videos={[
      staticFile("clips/onboarding.mp4"),
      staticFile("clips/dashboard.mp4"),
      staticFile("clips/checkout.mp4"),
    ]}
  />
);

export const RemotionRoot = () => (
  <Composition id="PhoneStack" component={Scene} durationInFrames={120} fps={30} width={1280} height={720} />
);
```

Clips take a root-relative `/…` path or an `http(s)` URL and play muted from the moment their
screen arrives; images work too. Screen recordings at 9:19.5 fit exactly; any aspect is
cropped to cover.
