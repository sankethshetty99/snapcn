## Usage

A three-beat intro, 108 frames at 30fps:

1. **Line** — the `lead` words fade up one at a time while the line drifts in.
2. **Chip** — the line re-sets with a rounded picture chip and the `trail`, then leans in
   until the chip takes the frame.
3. **Title** — `title` types itself over the picture, lifts away, and the mark and `brand` arrive.

```tsx
import { Composition, staticFile } from "remotion";
import { PortalIntro } from "@/components/snap-cn/portal-intro";

const Scene = () => (
  <PortalIntro
    lead="your launch video"
    trail="in code"
    image={staticFile("hero.jpg")}
    title="Introducing"
    brand="Acme"
  />
);

export const RemotionRoot = () => (
  <Composition id="PortalIntro" component={Scene} durationInFrames={108} fps={30} width={1280} height={720} />
);
```
