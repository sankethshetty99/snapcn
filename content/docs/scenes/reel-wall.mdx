## Usage

A ring of vertical clips on a 3D wall. It eases in from rest, moving on twos like the
reference it was fitted from, then keeps turning at an even speed for as long as the
composition runs — make the composition longer for a longer turn.

```tsx
// src/Root.tsx
import { Composition, staticFile } from "remotion";
import { ReelWall } from "@/components/snap-cn/reel-wall";

const Scene = () => (
  <ReelWall videos={[staticFile("clips/1.mp4") /* …your vertical clips */]} />
);

export const RemotionRoot = () => (
  <Composition
    id="ReelWall"
    component={Scene}
    durationInFrames={216}
    fps={24}
    width={1280}
    height={720}
  />
);
```

Clips take a root-relative `/…` path or an `http(s)` URL, play muted, and repeat around the
ring. Vertical 9:16 clips fit best; any aspect is cropped to cover. Pass clips at least as
long as the composition — a shorter clip stops on its last frame.
