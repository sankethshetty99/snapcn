A prompt composer in Prompt Send's style: a glass panel over a soft accent wash, a white writing surface, two icon buttons and a round send button. The placeholder writes itself while a cursor flies in from the edge and clicks the field. Then the shot cuts hard into the field, the placeholder is gone, and your prompt types at the caret. Use it for the "just describe it" beat of an AI product video.

## How it moves

**It cuts with Prompt Send.** Same glass panel, same writing surface, same wash, all from your theme. Change the wash with `accentColor`. The send button arms to ink once the first letter lands.


**Two shots, one card.** The close-up is the same card under a constant camera, pinned on the first letter. Nothing scales while it moves, so the type stays sharp.

**The cursor stays in the wide shot.** It clicks, and the cut leaves it behind, the way a real screen recording would.

**Typing is a keystroke a frame.** A space costs an extra beat. The caret holds solid while it types and blinks while it waits.

The length depends on the prompt: `clickTypeFrames(prompt)` returns it.

## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { ClickType, clickTypeFrames } from "@/components/snap-cn/click-type";

const prompt = "Build me a booking app";
const Scene = () => <ClickType prompt={prompt} />;

export const RemotionRoot = () => (
  <Composition
    id="ClickType"
    component={Scene}
    durationInFrames={clickTypeFrames(prompt)}
    fps={30}
    width={1280}
    height={720}
  />
);
```
