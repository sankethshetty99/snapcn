A cursor walks in and lands on a split action button: the label, a hairline divider and a chevron, in your primary colour. The button darkens as the cursor reaches it, gives a little on the click and springs back. The label slides out for a spinner, then the spinner slides out for a tick that draws itself. It's the deploy, publish or send beat in a launch video.

## How it moves

**Only the surface presses.** The fill gives by 3.5% and returns to exactly 1. The label never scales, so it never shimmers.

**One width, three labels.** The button is sized once (`width`, at 720p) for the longest label, so it never reflows under the cursor sitting on it.

## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { ButtonPress } from "@/components/snap-cn/button-press";

const Scene = () => <ButtonPress label="Publish" pending="Publishing…" done="Live" />;

export const RemotionRoot = () => (
  <Composition
    id="ButtonPress"
    component={Scene}
    durationInFrames={126}
    fps={30}
    width={1280}
    height={720}
  />
);
```
